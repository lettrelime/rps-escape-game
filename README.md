# 탈출 : 가위바위보 하나 빼기

## 프로젝트 소개

정체를 알 수 없는 공간에서 출구를 지키는 문지기와 `가위바위보 하나 빼기` 대결을 반복하는 MVP 웹게임입니다.
승리하면 기억 조각을 되찾고, 패배하면 기억을 잃습니다.

## 게임 규칙

- 플레이어는 가위, 바위, 보 중 총 두 번 선택합니다.
- 같은 손을 두 번 선택할 수 있습니다.
- 문지기도 가위, 바위, 보 중 두 손을 랜덤으로 선택합니다.
- 서로의 두 손이 공개된 뒤, 플레이어는 두 손 중 최종적으로 사용할 하나를 선택합니다.
- 문지기도 자신의 두 손 중 하나를 랜덤으로 남깁니다.
- 최종 선택끼리 일반 가위바위보 규칙으로 승패를 판정합니다.

## 점수 및 엔딩 규칙

- 시작 기억 조각: 0
- 승리: 기억 조각 +2
- 무승부: 변화 없음
- 패배: 기억 조각 -1
- 기억 조각이 5점 이상이면 HAPPY ENDING
- 기억 조각이 -3점 이하이면 BAD ENDING

## 실행 방법

별도의 설치 과정이 필요하지 않습니다.

`index.html`을 더블클릭하면 브라우저에서 바로 실행됩니다.
