# 탈출 : 가위바위보 하나 빼기

정체를 알 수 없는 공간에서 문지기와 **「가위바위보 하나 빼기」** 대결을 펼치고 탈출하는 싱글 플레이 웹게임입니다.

🎮 **[게임 플레이하기] https://lettrelime.github.io/rps-escape-game/**


## 프로젝트 소개

파이썬 기초 학습 중 `input()`과 `random.choice()`를 활용해 만들었던 간단한 게임 아이디어에서 출발했습니다.

이후 아이디어를 실제 웹게임으로 발전시키면서 게임 구조와 스토리를 다시 설계하고, HTML/CSS/JavaScript를 활용해 구현했습니다.

작은 프로젝트를 아이디어 단계에서 끝내지 않고 **기획 → 프로토타입 → 개선 → QA → 웹 배포**까지 직접 완주하는 것을 목표로 제작했습니다.


## 게임 방법

1. 첫 번째 손과 두 번째 손을 선택합니다.
   - 같은 패를 두 번 선택할 수도 있습니다.
2. 문지기도 가위·바위·보 중 두 패를 무작위로 선택합니다.
3. 서로의 두 패가 공개되면 최종 승부에 사용할 하나를 남깁니다.
4. 문지기도 자신의 두 패 중 하나를 무작위로 남깁니다.
5. 일반 가위바위보 규칙으로 승패를 결정합니다.


## 게임 진행 및 엔딩

게임은 총 **5라운드** 동안 진행됩니다.

각 라운드의 승리·무승부·패배가 누적되며, 현재 전적에 따라 기억이 돌아오거나 흐려지는 과정을 짧은 문구로 확인할 수 있습니다.

5라운드 종료 후:

- **승리 > 패배** → `HAPPY ENDING — 탈출`
- **승리 ≤ 패배** → `BAD ENDING — 고립`

## 실행 방법

### 웹에서 플레이

상단의 **게임 플레이하기** 링크를 통해 별도의 설치 없이 실행할 수 있습니다.

### 로컬에서 실행

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 실행할 수 있습니다.
